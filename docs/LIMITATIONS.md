# Limitations

Independent AmneziaWG **client**. Not a fork of amnezia-vpn/amnezia-client (GPLv3).

Included: import `.conf`, Connect, IPv4 site split, apps that bypass VPN, KillSwitch.

Not included: self-host, extra protocols, AWG 3.x, logging/backup, custom DNS UI.

KillSwitch crash leftover: Settings → Off, or `agg-cli kill-switch off`.
